# Bunko 文庫

**Public-domain classics in English, Chinese and Japanese, with ruby readings on every character and a reading companion beside the text.**

Bunko reads the interlinear JSON produced by [PocketPolyglot](https://github.com/lachlanchen/PocketPolyglot) (`../ZhJpBook`): each token carries its text, its reading (furigana or pinyin) and its grammar role, so the app can show furigana above kanji, pinyin above hanzi, switch between paired and interlinear layouts, and keep every book readable offline.

Only titles that pass a written rights check ship. The audit lives in `docs/catalogue.md`.

Status: brief in `BRIEF.md`. Sibling of [L & N](https://github.com/lachlanchen/L-And-N), which supplies the app shell and the publishing pipeline.
