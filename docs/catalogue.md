# Catalogue audit — 2026-09-23

The owner confirmed that the final translations were generated by Codex, not copied from the listed reference translations. Clearance therefore checks the **original author and work**. A modern reference filename alone is not a reason to hold a Codex-generated edition. This supersedes the earlier reference-based holds.

The machine-readable publication gate is [library-editions.json](library-editions.json). It inventories **336 editions/plans**: **150 ship** and **186 remain unpublished** (unfinished data, duplicate passes, unidentified rights, modern original works, or the established age-rating exclusions). The scan included 664 assembled/preview files representing 276 works, completed bilingual chunk manifests, and every remaining book plan. This is a review of the available collection, not a claim to have acquired every public-domain book.

Published texts use the owner's declaration about final Codex translations. Original-author dates and ancient-work provenance are recorded per edition. This is not a blanket worldwide copyright guarantee: modern originals still have territory-dependent terms. Previously listed Hesse, Hemingway and Faulkner editions were removed from the live catalogue because their authors' terms have not expired in all target markets. 金瓶梅, 肉蒲團 and 素女經 retain the agreed age-rating exclusion.

The exporter verifies complete source coverage and all published language layers. The repository validator checks each chapter's content, size, paragraph count and optional checksum before generating the index. Incomplete language overlays do not block an otherwise complete smaller language edition: Genji currently ships Japanese/Chinese because the English overlay no longer matches part of the base. Empty-source footnote markers are retained as annotations in their available languages. Sanguozhi with Pei's commentary includes all 2,130 commentary chunks; 198 unanchored notes remain at chapter ends, as in the source assembly.

Books and image payloads live only in [bunko-books](https://github.com/lachlanchen/bunko-books). The legacy `build_reader.py` CLI is retired; use `publish_library.py`, then the public repository's validator. See [publishing instructions](library-publishing.md).

Author references used for the added Japanese editions include [Aozora: Soseki](https://www.aozora.gr.jp/index_pages/person148.html), [Akutagawa](https://www.aozora.gr.jp/index_pages/person879.html), [Miyazawa](https://www.aozora.gr.jp/index_pages/person81.html), and [NDL: Genji](https://id.ndl.go.jp/auth/ndlna/00633493). Ancient Chinese author/work identifications follow the source plan and [Chinese Text Project](https://ctext.org/).
