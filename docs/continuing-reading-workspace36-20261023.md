# Continuing reading workspace

Ask, People, Places and Timeline use the same conversation. Each visual view
reopens an existing result; opening a tab or refreshing history does not generate
a new answer. Results near the selected passage are preferred, with recency as a
tie-breaker. Whole-book scope prefers earlier whole-book results.

Use **Continue from here** beneath an earlier answer to follow that branch, or
choose a saved visual result. Later unrelated questions do not enter that branch.
A follow-up can update one view while retaining the other views. **Start a new
topic** starts without an implicit parent. The compact scope control and @ picker
can broaden the question without moving the reading bookmark.

## Model context and storage

The server verifies parent ownership, book and thread before using a result.
The most recent six question/answer pairs in the selected branch enter model
context, along with the latest available snapshot of each visual group across
the full branch. This bounds context while retaining older diagrams. Unrelated
branches and other users' history are excluded.

Current excerpts provide exact quotation evidence. Prior diagrams and reliable
whole-book knowledge are labeled as background, not treated as fresh quotation
evidence. This is a reading aid, not a claim of exhaustive analysis or guaranteed
literary accuracy. Personal generated results remain in encrypted account-bound
history and are never added to the shared public guide cache. Fixed canonical
guides retain their existing public reuse behavior.

## Visuals

Character colors stay stable when nodes are reordered. Rounded links, centered
focused neighborhoods, tree and graph layouts, and saved zoom/selection help
larger diagrams remain navigable. Long timelines use expandable events and a
compact story sequence; actual dates require verified source evidence. Timeline
order and selection survive tab changes. Geographic pins still require evidence
or an explicit reader choice; fictional places can use the story map.
