# Mac window recovery

Mac1.0.15(44) adds **Window → Show Bunko** with Command-N. The command remains
available after closing the main window and restores the existing reader or
conversation. Dock reopening and reader menu commands use the same window
recovery path. The window and WebKit document are retained, so reopening does
not reload the book or discard an unsent message.

Two native regression cases exercise Close Window followed by the actual Window
menu command. They check window/document identity, reading position and ruby,
then the active conversation branch, draft and unchanged generation count.
They run only in the isolated Debug harness, without foreground activation.

## Delivery status

Source is prepared. Native validation and replacement delivery are pending;
this is not part of the previously delivered build43. The current public Mac
version remains available. iOS, Watch, Android and the reading service are
unchanged by this Mac correction.
