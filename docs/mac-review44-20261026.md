# Mac window recovery

Mac1.0.15(44) adds **Window → Show Bunko** with Command-N. The command remains
available after closing the main window and restores the existing reader or
conversation. Dock reopening and reader menu commands use the same window
recovery path. The window and WebKit document are retained, so reopening does
not reload the book or discard an unsent message.

Native regression checks now invoke AppKit menu items, including validation and
target/action dispatch. Earlier reader command checks dispatched web events
directly and could miss a missing or disabled native menu item.

The expanded 22-check suite covers three close/reopen cycles, Settings while the
window is closed, and the Dock reopen delegate with closed and visible windows.
It checks window/document identity, exact reading position and ruby, the active
conversation branch and draft, and the relationship filter and selected person.
Reopening must not start another generation. Existing offline, equation, figure,
map, timeline and resize checks remain part of the suite.

The native suite runs in the isolated Debug harness without foreground
activation. The Dock delegate is invoked directly; this is not a physical Dock
click or keyboard-focus test. Native results remain pending.

## Delivery status

Source is prepared. Native validation and replacement delivery are pending;

version remains available. iOS, Watch, Android and the reading service are
unchanged by this Mac correction.

web production build pass. Those checks do not replace native qualification.
