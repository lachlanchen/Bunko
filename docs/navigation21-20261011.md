## Changes

- Existing languages offer direct reading instead of duplicate translation requests.
  Names, native names and tags are recognized, with script and classical/modern
  distinctions preserved. Cached chapters are reused, including offline.
- Language selection order defines reading order. Chip 1 is main; deselecting it
  promotes the next and reselecting appends. Main-text-only mode follows the chosen
  language. Numbered/color-coded Settings chips replace repeated reading labels.
  At least one language stays selected, and the reading paragraph is retained.
- Translation requests opened from book details or reading Settings automatically
  use the current book. The book homepage has a top-right Settings shortcut.
  Library Settings still allows a general request, without stale book details.
- Settings has a labelled, larger Close button which stays visible while its body
  scrolls. Tapping the backdrop also closes it; closing preserves reading position.
- A deliberate right swipe closes an open panel first, then returns from the reader
  to book details, and from book details to the library. Text selection, form controls
  and ordinary vertical scrolling retain their existing handling.
- The request opens a prefilled GitHub issue for the reader to review and submit.
  It does not post automatically or generate a translation instantly.
