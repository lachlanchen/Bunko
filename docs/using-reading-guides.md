# Reading with maps, people and events

Open a book and choose **Reading companion** from the reader. The current book
and passage come with you. Ask about the passage, a chapter or the whole book;
use a reference chip to make that scope explicit.

- **People:** select a person or connection to see the explanation and available
  source passages. Smaller graphs arrange vertically on phones.
- **Places:** tap a place, follow a connected place or use **Focus on map**.
  Previous and next controls keep navigation inside the expanded map. Modern
  boundaries provide geographic reference; connecting lines are not exact roads
  or historical borders. Source and uncertainty labels remain beside the result.
- **Timeline:** move through the events in text order or by date where dates are
  available. Open an event's source passage to return to the book.

Continue a saved result with another question to extend it. Reopening an existing
guide does not by itself generate another answer. Use Back to return to the
passage where you stopped.

In reader Settings, change main text, ruby and interface size independently.
Main text reaches 250%; interface text reaches 150%. Larger controls do not
require enlarging the book text, and reduced-motion preferences are respected.
